# Discover Tooling Policy

1. Start at this Skill's root node; read metadata for only its direct children. Descend into each branch relevant to the current operation and Host-observed capability, repeating at any depth.
2. Multiple Capability, Interface and Family branches may apply to one operation. A Family does not imply an Interface or Capability, and a tool name or version does not prove an applicable branch.
3. Do not read an unselected node body or its References. No applicable tool means report the missing capability; do not invent a route or installation.
