# 安裝復原

安裝期間若程序被中斷，可能會看到 Work、Tooling 或 Global `AGENTS.md` 只有部分項目完成更新。安裝器會保留用來判斷進度的交易資料，供下次執行時檢查。

## 1. 如何繼續安裝

1. 保留安裝目錄、交易資料與先前顯示的錯誤訊息。
2. 重新執行相同的安裝命令，使用原本的安裝位置與選項。不要加上 `--dry-run`，因為它不會處理待復原的交易。
3. 查看安裝器的結果。它會逐一檢查 Work、Tooling 與 Global `AGENTS.md` 的紀錄及現有檔案；只有通過驗證的內容才視為安裝完成。

## 2. 何時需要停下來

若安裝器無法確認檔案身分、發現內容被其他程序修改，或回報復原失敗，請保留現場與完整錯誤訊息。不要自行刪除安裝目錄或交易資料；這些內容可能是判斷已完成操作所需的證據。

安裝器會先準備並驗證新內容，再更新正式安裝目錄。中斷後重新執行時，它只會在能確認安全的情況下復原或繼續安裝。安裝狀態檔的用途見[安裝狀態](install-state.md)。
